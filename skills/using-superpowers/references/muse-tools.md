# Muse Compatibility Note

The personal edition is Codex-only. This file records source vocabulary for a
future port and is not an active Muse model or delegation path.

| Action | Typical Muse tool |
|---|---|
| Read a file | `read_file` |
| Edit a file | `edit_file` |
| Run a command | `bash` |
| Search files | `search` |
| Track work | `write_todos` |

If ported, keep planning, diagnosis, review, re-review, and integration in
the main session. Delegate only an explicitly authorized implementation unit;
the worker may test, self-review, and debug its own work but may not spawn a
reviewer, analyst, planner, or nested worker. Do not copy model settings from
this compatibility note.
