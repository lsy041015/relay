# Pi Compatibility Note

This personal edition is Codex-operated. Pi terms are retained only for source
compatibility and are not an active model or delegation guide.

| Action | Typical Pi tool |
|---|---|
| Dispatch an explicitly authorized implementation worker | an installed `subagent` tool |
| Track work | an installed todo tool or plan file |

If no worker tool exists, execute inline rather than fabricating a dispatch.
When porting, keep planning, diagnosis, review, re-review, and integration in
the main session. A worker may test, self-review, and debug its bounded task,
but may not create another worker or a non-implementation role. Do not copy
model, chain, or parallel settings from this compatibility note.
